## 🌍 À propos de la plateforme

### Qu'est-ce que Grands Projets ?

**Grands Projets** est une carte interactive qui rassemble, au même endroit, les grands projets d'aménagement urbain et de mobilité : nouvelles lignes de tramway, pistes cyclables, projets d’urbanisme, grands chantiers, etc.

L’objectif : rendre ces informations **compréhensibles et accessibles** pour tous, en montrant concrètement *où* se situent les projets, *ce qu’ils changent* et *où en est leur avancement*.

### Pour qui ?

- **Citoyens et riverains**  
  Comprendre les projets qui impactent votre quartier, anticiper les travaux, suivre les évolutions dans le temps.

- **Élus et collectivités**  
  Disposer d’une vision consolidée des projets à l’échelle d’une ville ou d’une métropole, faciliter la concertation et le dialogue avec les habitants.

- **Services techniques et bureaux d’études**  
  Centraliser les informations, vérifier les cohérences entre projets, partager une base cartographique commune avec vos partenaires.

- **Journalistes, chercheurs, étudiants**  
  Explorer les grands chantiers, analyser les dynamiques urbaines et illustrer des articles ou études avec des cartes lisibles.

## ⭐ Fonctionnalités principales

- **Carte interactive multi‑villes**  
  Navigation fluide (zoom, déplacement), géolocalisation, fonds de carte variés (OSM, satellite, historiques) et changement de ville en un clic.

- **Catégories de projets**  
  Affichage par grands thèmes : transport/mobilité (tram, métro, bus, vélo…), urbanisme, grands projets d’aménagement, travaux et chantiers.

- **Filtres avancés**  
  Filtrage par type de projet, par statut (en cours, planifié, terminé, concertation), par ligne (T6, T9…), par secteur ou commune selon les données disponibles.

- **Fiches projet détaillées**  
  Pour chaque projet : description, calendrier, acteurs, visuels (plans, rendus, photos), liens vers les documents officiels et tracé mis en avant sur la carte.

- **Vue dédiée aux travaux**  
  Liste des chantiers, filtrage par nature de travaux, état d’avancement et période, avec localisation précise sur la carte.

- **Contribution**  
  Pour les utilisateurs habilités : proposition de nouveaux projets ou mises à jour (tracé, description, documents), avec un flux de validation par les admins.

- **Mode sombre et ergonomie mobile**  
  Interface adaptée automatiquement au thème clair/sombre, navigation optimisée sur mobile (panneaux plein écran, boutons accessibles au pouce).

## 🗺️ Ce que vous pouvez faire avec la carte

- **Voir en un coup d’œil les grands projets**  
  Tramway, métro, bus, vélo, urbanisme, travaux : chaque type de projet a son style et sa couleur.

- **Filtrer les informations selon vos besoins**  
  Afficher seulement les projets en cours, une ligne spécifique (ex. T6, T9), ou les chantiers dans un secteur donné.

- **Ouvrir la fiche détaillée d’un projet**  
  Description, calendrier, acteurs, documents officiels, visuels… Chaque projet dispose d’une fiche claire qui explique l’essentiel.

- **Explorer les travaux en cours**  
  Une vue dédiée permet de lister les chantiers, de voir leur état d’avancement et les périodes d’intervention.

- **Changer de ville ou de territoire**  
  La plateforme est pensée pour être **multi‑villes** : on peut passer d’une agglomération à une autre sans changer d’outil.

## 💡 Exemples de cas d’usage

- **Préparer une réunion publique**  
  Afficher sur la carte l’ensemble des projets d’un secteur, ouvrir les fiches projet, et partager l’URL correspondante avec les participants.

- **Informer les riverains d’un chantier**  
  Pointer directement sur la carte le périmètre des travaux, les dates clés et les impacts principaux.

- **Comparer plusieurs scénarios de mobilité**  
  Visualiser, pour une même ville, les lignes de tramway, les projets vélo et les projets d’urbanisme pour comprendre les interactions.

- **Documenter un article ou un rapport**  
  Utiliser la carte pour illustrer un sujet (nouvelle ligne, requalification d’axe, etc.) et renvoyer vers les fiches pour plus de détails.

## 🚀 Utilisation en 3 étapes

1. **Choisir la ville**  
   Sélectionnez la ville ou le territoire qui vous intéresse dans le menu dédié.

2. **Choisir un type de projet**  
   Cliquez sur une catégorie (transport, vélo, urbanisme, travaux…) pour afficher la couche correspondante sur la carte.

3. **Explorer les projets**  
   - Cliquez sur un projet sur la carte pour voir un résumé rapide.
   - Ouvrez la fiche détaillée pour accéder à la description, aux documents et aux visuels.

Sur mobile, la navigation est optimisée pour un usage tactile : panneaux superposés, vue carte plein écran, boutons accessibles au pouce.

## 🏙️ Villes couvertes

La plateforme est conçue pour être **multi‑territoires**. Chaque ville dispose :

- De ses propres fonds de carte et couleurs d’interface.
- De ses données de projets (transport, urbanisme, travaux…).
- D’un paramétrage spécifique (filtres, couches, branding).

La liste des villes actuellement disponibles peut évoluer. Pour connaître l’état des lieux ou ajouter un nouveau territoire, n’hésitez pas à prendre contact.

## 👥 Contribuer aux projets

Grands Projets n’est pas seulement une carte “en lecture seule” :

- **Les utilisateurs habilités** peuvent proposer de nouveaux projets ou mettre à jour des informations (tracé, description, documents…).
- Les contributions sont **modérées** avant publication afin de garantir la qualité des données.
- Il est possible de gérer les contributions **ville par ville**, avec des droits adaptés (ex. administrateurs d’une agglomération).

Si vous représentez une collectivité et souhaitez ouvrir un espace de contribution pour vos projets, contactez‑nous pour définir les modalités (types de projets, validation, flux de données, etc.).

## 💻 Pour les développeurs

Même si ce README est volontairement orienté “fonctionnel”, la plateforme reste pensée pour être **simple à héberger et à faire évoluer**.

- **Type d’application** : site web statique, côté client uniquement.
- **Cartographie** : [Leaflet](https://leafletjs.com/) pour l’affichage de la carte et des couches.
- **Backend & données** : [Supabase](https://supabase.com/) (PostgreSQL + stockage de fichiers) pour les projets, les filtres, les villes, etc.
- **Tests** : suite de tests end‑to‑end avec Playwright.

### Démarrage rapide

```bash
# 1. Cloner le repository
git clone https://github.com/your-org/grandsprojets.git
cd grandsprojets

# 2. Installer les dépendances (tests et outils)
npm install

# 3. Lancer le serveur de développement
npm run start
# → Ouvre http://localhost:3000
```

### Tests

```bash
# Lancer les tests en mode UI (flux de contribution)
npm run test:contrib:ui

# Lancer l’ensemble des tests
npm test
```

Pour une description détaillée de l’architecture (modules JavaScript, structure Supabase, design system CSS), se référer aux commentaires dans le code et aux fichiers de documentation internes.
